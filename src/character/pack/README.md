# Characters for three.js — Blocky + Chibi

One `Character` class, two styles:

- **blocky** — voxel style, square head and limbs
- **chibi** — big head and small body with smooth, rounded shapes

Both styles are the same height by default: an average-height character is about 1.05 units to the top of the head (a bit more with hair or hats), so they can share a scene.

Every config works in both styles, so any character can be switched between them at runtime.

```
characters.js          Character class, PRESETS, style conversion  ← start here
blocky-character.js    the blocky generator (BlockyCharacter)
blocky-presets.js      25 blocky designs
chibi-character.js     the chibi generator (ChibiCharacter)
chibi-presets.js       25 chibi designs
character-lab.html     browser customizer for both styles
glb/blocky, glb/chibi   every preset exported with its animations
export-glb.js          regenerates glb/ (npm i && node export-glb.js)
```

## Quick start

```js
import * as THREE from 'three';
import { Character, PRESETS } from './characters.js';

const a = new Character(THREE, { type: 'chibi' });                    // default chibi male
const b = new Character(THREE, { type: 'blocky', body: 'female' });   // default blocky female
const c = new Character(THREE, PRESETS.chibi.santa);
const d = new Character(THREE, { ...PRESETS.blocky.skater, type: 'chibi' });   // blocky design, chibi style

scene.add(a.root, b.root, c.root, d.root);
a.play('Wave');               // 'Walk' | 'Idle' | 'Wave'   (riders: 'Ride' | 'Idle') — see a.clipNames
// each frame:
a.update(delta);

a.set({ type: 'blocky' });            // switch style; position and animation are kept
a.set({ hair: { style: 'bun', color: '#2b1b14' } });
a.toJSON();                           // save the config
Character.random('chibi');            // random config for a style
```

Sizes: the defaults are `{ chibi: { scale: 0.06 }, blocky: { px: 0.0327 } }` (equal heights). Override either with the third argument, e.g. `new Character(THREE, config, { blocky: { px: 0.056 } })` for the original, taller blocky size.

## Config

| Property | Values | Styles |
|---|---|---|
| `type` | `chibi`, `blocky` | both |
| `body` | `male`, `female` | both |
| `build` | `skinny`, `average`, `chubby` | both |
| `height` | `short`, `average`, `tall` | both |
| `skin`, `lips` | any CSS color | both |
| `eyes` | `{ style, color }` — styles `round, big, closed, dots` (blocky uses the color only) | both |
| `cheeks` / `freckles` | `true` / `false` | chibi / blocky |
| `hair` | `{ style, color }` — `none, buzz, short, quiff, spiky, afro, long, bob, ponytail, bun, pigtails, mohawk`; chibi adds `swept, curly` | both |
| `facialHair` | `{ style, color? }` — `none, stubble, moustache, goatee, beard`; chibi adds `fullBeard` | both |
| `top` | `{ style, color, accent? }` — `tshirt, polo, longsleeve, tanktop, hoodie, jacket, sweater, dress` | both |
| `bottom` | `{ style, color, accent? }` — `pants, jeans, joggers, shorts, skirt, leggings, bare`; blocky adds `widePants` | both |
| `shoes` | `{ style, color, accent? }` — `simple, sneakers, boots, bare`; blocky adds `hightops` | both |
| `accessories` | names or `{ type, color?, accent?, side? }` | see below |

**Accessories**

| Slot | Both | Chibi only | Blocky only |
|---|---|---|---|
| Head | cap, beanie, headphones | santaHat | |
| Face | glasses, sunglasses, earrings | | |
| Body | scarf, tie, watch | bowtie, belt, gloves | camera |
| Back | backpack | | guitar |
| Hands | briefcase, book, phone, coffee, tablet | icecream, balloon | |
| Ride | skateboard, hoverboard | | |

When a style lacks a part, it uses the closest match from `FALLBACKS` in `characters.js` (for example santaHat → beanie, fullBeard → beard, hightops → sneakers, guitar → backpack) or leaves it out. `character.warnings` lists what changed. The original config is kept, so switching back restores everything.

## Adding your own parts

Each style has its own registries: `BlockyCharacter.registerAccessory(...)` and `ChibiCharacter.registerAccessory(...)`, plus `registerHair`, `registerTop`, `registerBottom` and `registerShoes`. Register the same name in both styles to make a part work everywhere, or add an entry to `FALLBACKS`.

## GLB files

```js
const gltf = await new GLTFLoader().loadAsync('glb/chibi/santa.glb');
scene.add(gltf.scene);
const mixer = new THREE.AnimationMixer(gltf.scene);
mixer.clipAction(THREE.AnimationClip.findByName(gltf.animations, 'Wave')).play();
```

For speckle-free shadows on the flat faces, set `light.shadow.bias = -0.0004` and `light.shadow.normalBias = 0.02`.

The chibi style is inspired by "Low Poly Characters (PACK)" by micaelsampaio (CC-BY-4.0). No geometry or textures from that pack are used; every mesh is generated by code.
