Set up this computer for the office

The office is served over HTTPS on this network, which it needs for the microphone. Its certificate comes from the office server itself, so each computer has to be told once to trust it. This takes about a minute.

1. Download the certificate

2. Install it

Windows

  1. Open the downloaded office-root-ca.crt.
  2. Choose Install Certificate, then Local Machine (or Current User if you are not an administrator).
  3. Choose Place all certificates in the following store, then Browse and pick Trusted Root Certification Authorities.
  4. Finish, accept the warning, and restart the browser.

macOS: open the file (Keychain Access), add it to System, double-click it, expand Trust, and set When using this certificate to Always Trust.

Android / iPhone: open the file and follow the install prompt (on iPhone also enable it under Settings, General, About, Certificate Trust Settings).

Firefox keeps its own list: Settings, Privacy & Security, Certificates, View Certificates, Authorities, Import (or turn on security.enterprise_roots.enabled to use the system list).
